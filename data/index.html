Using the data

How to cite

The data are free to use and adapt. In return, cite the paper the data belong to, and the package too, by its DOI where it has one. Each package's README gives the full reference.

For LEAP researchers

Adding your data

Every LEAP package follows one layout, so that a reader who has used one dataset can use them all. The data stay on GitHub; this page is the index to them.

  1. 1. One repository per paper

    Create it in the leapstellenbosch organisation on GitHub, named after the paper. Write to us for access.

  2. 2. Package the data

    Data as UTF-8 CSV, a README with the paper's reference and the sources, a CODEBOOK, a LICENSE (CC BY 4.0), a CITATION.cff and a load.R script.

  3. 3. Release it

    Publish a GitHub release and archive it on Zenodo, which gives the package a permanent DOI.

  4. 4. List it here

    Add one entry to _data/datasets.yml. The table updates within a minute.
