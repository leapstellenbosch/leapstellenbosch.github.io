Using the data

How to cite

The data are free to use and adapt. In return, cite the paper named on the dataset's card, and the repository too if the journal allows it. Each repository's README gives the full reference.

For LEAP researchers

Depositing data

Every LEAP release follows one package layout, so that a reader who has used one dataset can use them all.

  • Plain files

    Data as UTF-8 CSV only. No spreadsheets, no proprietary formats. Missing values are empty strings.

  • Documented

    A README, a LICENSE (CC BY 4.0), a CODEBOOK and a machine-readable variables.csv.

  • Loadable

    A load.R script that reads every file with the right types, so replication starts with one line.
